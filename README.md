# TCPCホールディングス コーポレートサイト リニューアル案

株式会社TCPCホールディングスのコーポレートサイトを作り直すデモです。先方と交渉中のため、**このリポジトリは非公開（Private）のまま運用します。** GitHub Pages では公開しないでください（無料プランではリポジトリが非公開でもサイトは誰でも見られます）。

## 見方

`index.html` をブラウザで開きます。`assets` フォルダの画像（波・リボンのパーツ）を使っているので、フォルダごと扱ってください。写真はネット上の画像を表示しているため、表示にはネット接続が必要です。

## 公開前に差し替えるもの

- 写真：Unsplash の仮画像。自社で撮影した写真に差し替える
- グループ各社とTCPCのロゴ：各社サイトの画像を直接表示している。正式なロゴデータに差し替える
- 本社の住所・郵便番号、会社概要の数値
- ニュース記事・プライバシーポリシーのリンク先
